## Req 001 – Acceso del directivo

**Descripción:** El directivo de la institucion educativa debe poder iniciar sesion y así acceder a las estadisticas.

**Prioridad:** P0

**Criterios de aceptación:**

**Scenario: Selección de tipo de cuenta durante el registro**

```gherkin
Como directivo,
Quiero iniciar sesión en la plataforma,
Para acceder a las estadísticas y herramientas de análisis.
```
